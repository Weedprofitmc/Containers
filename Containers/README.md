# BetterRpContainers 2.2.0

Плагин контейнеров и аукциона для Paper 1.21.x / Java 21.

## Сборка

```bash
mvn clean package
```

Готовый JAR появится в `target/BetterRpContainers-2.2.0.jar`.

## Установка

1. Убедитесь, что сервер использует Java 21.
2. Установите Paper 1.21.x, Vault и совместимый экономический плагин (например, EssentialsX Economy).
3. Поместите JAR в `plugins/` и запустите сервер.

## Хранение данных

- `plugins/BetterRpContainers/config.yml` — настройки и ожидающие офлайн-награды.
- `plugins/BetterRpContainers/containers.yml` — активные контейнеры, ставки, история и предметы.
- `plugins/BetterRpContainers/stats.yml` — статистика игроков.

При первом запуске 2.2.0 активные контейнеры автоматически переносятся из старого `config.yml` в `containers.yml`. Предметы поддерживают оба формата хранения: Bukkit ItemStack и карты, созданные через `ItemStack.serialize()`.

Изменения открытого GUI редактора сохраняются при закрытии, каждые 5 секунд и при штатном выключении плагина. Файл контейнеров записывается через временный файл с атомарной заменой, если файловая система поддерживает такую операцию.

## Важно перед обновлением

Сделайте резервную копию папки `plugins/BetterRpContainers/`. Не удаляйте старые `config.yml` и `stats.yml` до успешного запуска новой версии и проверки контейнеров.
